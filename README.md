# SQLite 免费中文恢复练习

先读 [中文教程](TUTORIAL.md)，按顺序执行，不需要购买销售包。

- `rescue.py`：备份／校验／不覆盖恢复工具。
- `make_sample.py`：原创安全样本生成器；不含真实个人数据。
- `check_sample.py`：只读业务验收。
- `qa_lab.py`：在新的临时目录里自动重跑教程，包括预期失败步骤。
- `evidence/`：制作方实际复跑记录；不是第三方审计认证。
- `LICENSE`、`SOURCES.md`：许可与官方来源。

运行 `python3 qa_lab.py` 可复跑验收，不改动当前目录已有数据库。本材料仅限教学，不是生产灾备方案；不会自动切换应用数据库，不提供托管或人工支持承诺。

下载：仓库上方 **Code → Download ZIP**，解压后进入含 `qa_lab.py` 的目录。Python 3.10+；实际仅在 Linux / Python 3.12.14 / SQLite 3.53.1 验证，其他平台未验证，恢复所在文件系统须支持硬链接。
